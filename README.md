# 📊 Proyecto: Domina Excel con IA  
## Análisis y Proyección de Ventas de Materiales de Construcción

---

## 📌 Descripción

Este proyecto tiene como objetivo aplicar herramientas de inteligencia artificial integradas en Excel para analizar y proyectar el comportamiento de ventas de materiales de construcción.  

Se utilizaron funciones automatizadas, análisis predictivo y visualizaciones dinámicas para transformar datos básicos en información estratégica que apoye la toma de decisiones.

---

## 🎯 Tema Elegido

**Análisis y proyección de ventas de materiales de construcción.**

El proyecto simula el comportamiento comercial de distintas sedes y vendedores, permitiendo evaluar desempeño y tendencias futuras.

---

## 📂 Fuente de Datos

Base de datos creada manualmente con registros simulados de ventas mensuales (50 registros).

La tabla contiene las siguientes columnas:

- Fecha  
- Vendedor  
- Producto  
- Cantidad  
- Precio Unitario  
- Total Venta  
- Sede  

Los datos fueron estructurados para facilitar análisis dinámicos mediante tablas dinámicas y herramientas predictivas.

---

## 🤖 Herramientas de IA Utilizadas

Durante el desarrollo del proyecto se utilizaron las siguientes herramientas de inteligencia artificial integradas en Excel:

- **Ideas en Excel** → Generación automática de análisis, patrones y gráficos sugeridos.
- **Hoja de Pronóstico** → Análisis predictivo para estimar ventas futuras.
- **Tablas dinámicas** → Segmentación automática de datos por mes, sede y vendedor.

Estas herramientas permitieron automatizar el análisis y mejorar la interpretación de resultados.

---

## ❓ Pregunta Clave

> ¿En qué mes se proyectan mayores ventas y qué sede presenta mejor desempeño?

Esta pregunta orientó el análisis y la construcción de visualizaciones.

---

## 📈 Resultados del Análisis

Mediante el uso de gráficos automáticos, tablas dinámicas y proyecciones se logró:

- Identificar el comportamiento mensual de las ventas.
- Determinar la sede con mayor volumen de facturación.
- Proyectar tendencias futuras de ventas.
- Visualizar patrones de crecimiento comercial.

---

## ✅ Conclusiones

El análisis permitió comprender el comportamiento mensual de las ventas y proyectar tendencias futuras mediante herramientas predictivas integradas en Excel. Se identificó la sede con mejor desempeño comercial y el mes con mayor crecimiento proyectado.  

La inteligencia artificial en Excel facilitó la generación automática de visualizaciones y análisis, optimizando la interpretación de datos y fortaleciendo la toma de decisiones basada en información cuantitativa.
